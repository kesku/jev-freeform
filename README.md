## Setup

Node.js 22+ and a TypeSafe API key.

```sh
git clone https://github.com/kesku/jev-freeform.git
cd jev-freeform
npm install
export TYPESAFE_API_KEY="your-key"
npm start
```

Open http://127.0.0.1:4177.
